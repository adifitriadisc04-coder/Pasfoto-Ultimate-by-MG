AILatar & pakaian

Mode lokal tanpa API: bekerja pada latar polos (mis. merah), warna latar diambil dari tepi atas foto.

Pengaturan API key

Key dikirim langsung dari browser ke penyedia, tidak lewat server lain. Foto murid akan diunggah ke penyedia AI; pastikan ada izin orang tua/sekolah.

Database template pakaian

3Tata letak

Slot berurutan: baris tegak dulu (kiri→kanan, atas→bawah), lalu foto miring. Isi kolom slot di tiap foto, mis. 1-5 atau 1,3,6-8.

4Pembagian per lembar

Foto dikelompokkan berurutan per lembar. Lembar terakhir yang kurang orang dibagi ulang otomatis. ZIP bisa dibuka dengan WinRAR/7-Zip.

★Pratinjau lembar

Lembar 1 / 1

Agar ukuran tetap presisi: cetak di kertas 4R (4×6 inci), skala 100% / Actual size, matikan "Fit to page" dan "Borderless expansion". Jika lewat toko foto, serahkan file PNG/JPG hasil unduhan (sudah bermetadata 300 dpi).

5Kolektif ke kertas besar

Setelah lembar 4R final, susun beberapa lembar ke satu kertas studio agar cetak sekali jalan. Semua tetap 300 dpi.

Halaman 1 / 1

Ukuran 10RS berbeda antar studio; bila studio Anda memakai ukuran lain, pilih Kustom. Saat cetak, pilih ukuran kertas yang sama dan skala 100%.
